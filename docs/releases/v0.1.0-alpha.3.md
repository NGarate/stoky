# Stoky v0.1.0-alpha.3

Tercera alpha de Stoky. La aplicación es la misma que en
[v0.1.0-alpha.2](https://github.com/NGarate/stoky/releases/tag/v0.1.0-alpha.2):
lo que cambia es cómo se instala. El repositorio y la imagen son **públicos**, y
un script prepara la instalación por ti.

> **Versión de prueba.** Conserva copias de seguridad y limita el acceso a personas
> de confianza.

## Novedades

- **Sin cuenta de GitHub.** Los archivos de instalación y la imagen
  `ghcr.io/ngarate/stoky` se descargan sin iniciar sesión: ya no hacen falta
  `gh auth login`, tokens con `read:packages` ni `docker login`.
- **`install.sh`.** Descarga los archivos de esta versión, comprueba cada uno con
  `SHA256SUMS`, ajusta sus permisos y crea `.env` con las dos claves secretas ya
  generadas. No cambia ningún valor que ya tengas, no sustituye archivos distintos
  de una instalación existente y **nunca arranca nada**: revisas `.env` y arrancas
  Stoky tú. Puedes ejecutarlo de nuevo sin riesgo.

## Instalación

Lee la [guía de instalación de esta versión](https://github.com/NGarate/stoky/blob/v0.1.0-alpha.3/docs/INSTALL.md).
En una carpeta vacía:

```bash
STOKY_RELEASE=v0.1.0-alpha.3
for asset in install.sh SHA256SUMS; do
  curl --fail --location --output "$asset" \
    "https://github.com/NGarate/stoky/releases/download/${STOKY_RELEASE}/${asset}"
done
grep -E '  install\.sh$' SHA256SUMS | sha256sum -c
less install.sh
bash install.sh
```

Después rellena `DOMAIN` y `ACME_EMAIL` en `.env`, revísalo y arranca:

```bash
docker compose config --quiet
docker compose pull
docker compose up -d --wait --wait-timeout 180
```

Imagen: `ghcr.io/ngarate/stoky:v0.1.0-alpha.3` (**Linux amd64**). La guía
mantiene también la instalación a mano, sin el script.

## Antes de actualizar desde v0.1.0-alpha.2

`docker-compose.yml` y `traefik.yml` no cambian y no hay migraciones nuevas. Haz
la copia de seguridad que describe la guía, pon `STOKY_VERSION=v0.1.0-alpha.3` en
tu `.env` y ejecuta `docker compose pull && docker compose up -d --wait --wait-timeout 180`.
No uses `install.sh` para actualizar: se niega a sustituir archivos de una
instalación existente, a propósito.

Si vienes de la alpha.1, sigue antes las indicaciones de las
[notas de la alpha.2](https://github.com/NGarate/stoky/releases/tag/v0.1.0-alpha.2).

## Límites conocidos

Los mismos que en la alpha.2: sin HEIC/HEIF, registro abierto sin invitaciones,
recuperación de contraseña ni segundo factor, solo amd64, y pendientes las
comprobaciones humanas de lector de pantalla, Safari iOS y tableta de cocina.
Consulta [estado](https://github.com/NGarate/stoky/blob/v0.1.0-alpha.3/docs/STATUS.md)
y [seguridad](https://github.com/NGarate/stoky/blob/v0.1.0-alpha.3/SECURITY.md).
Comunica errores en [Issues](https://github.com/NGarate/stoky/issues), sin
secretos ni tickets con datos personales.

## Verificación

`install.sh` tiene pruebas de comportamiento que se ejecutan en la imagen de la
CI (Alpine) y con `umask 077`, y se ha probado contra una versión publicada en
una carpeta vacía y sin credenciales: descarga, comprobación, `.env` generado,
`docker compose config` y `docker compose pull` de las cuatro imágenes. La CI
vuelve a arrancar la imagen publicada a través de Traefik antes de etiquetarla.
La emisión de certificados de Let's Encrypt depende de tu dominio y no se
verificó con un dominio público.

## English

Same application as alpha.2; what changes is installation. The repository and
the image are now public, so no GitHub account, token or `docker login` is
needed. The attached `install.sh` downloads this release's files, verifies each
against `SHA256SUMS`, sets their permissions and creates `.env` with both
secrets generated. It never changes a value already set, never replaces a file
of an existing installation, and never starts anything: you review `.env` and
start Stoky yourself. Follow the
[versioned installation guide](https://github.com/NGarate/stoky/blob/v0.1.0-alpha.3/docs/INSTALL.md).

**Upgrading from alpha.2:** no Compose, Traefik or database changes. Back up,
set `STOKY_VERSION=v0.1.0-alpha.3`, then pull and start. Do not use
`install.sh` to upgrade. Coming from alpha.1, follow the alpha.2 notes first.
